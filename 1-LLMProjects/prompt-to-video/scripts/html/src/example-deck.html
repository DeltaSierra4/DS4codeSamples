Video gen. Two engines, one narration. Write the script first; every other number follows from its timing. Pick by where it has to go: /video-full makes an mp4 for a slide or a post; /video-quick makes one HTML file that opens in any browser with no player and no network. What the build checks: 77 player checks on the schedule and clock, 66 track selectors proved inside their own scene, 0.00 seconds of timing error, measured not calculated. The same ninety seconds is 2700 KB as an mp4 and 56 KB as self contained HTML. One travels anywhere, the other travels light. Six rules that keep a deck seekable: no CSS transition, no setTimeout, anything that is not a CSS property is a compute track, no webfonts or remote images, a second track on one property must be additive, and no em dashes in visible copy.
